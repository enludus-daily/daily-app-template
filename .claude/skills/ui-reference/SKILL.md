# 流行りのアプリと StudyReel を参考に画面を作る

本人の希望（2026-11-09）：「StudyReel の UI を参考にしたり、流行ってるアプリの UI とかを参考にしたりしてほしい」。
トーン（色・書体・線・影）の数値は `app-quality-bar` の `references/look.md` §0（StudyReel の実測）が正。このスキルは「画面の組み立て・動き・気持ちいい瞬間」を外から借りるためのもの。

## 1. 毎日、参考のアプリを 2 つ決める（画面を作る前）
- **1 つは StudyReel**（トーンの基準。`look.md` §0）
- **もう 1 つは、題材の組み合わせ（`idea-fusion`）に近い、いま流行っているアプリ**。下の表から選ぶか、その日に調べる（App Store のランキング・Editors' Choice・[Apple の Liquid Glass のギャラリー](https://www.macrumors.com/2026/04/06/apple-liquid-glass-design-gallery-update/)・[Screens Design](https://screensdesign.com/) などのスクショ集）
- 参考にするアプリの画面を実際に見て（スクショ集や App Store のスクショ）、**借りるもの**を 3 つ、具体的に書く：「〈アプリ〉の〈画面〉の〈どこ〉を、うちの〈画面〉の〈どこ〉に」

| 流行りのアプリ | 借りられるもの（仕組みの型） |
|---|---|
| Pokémon Sleep | 朝の「結果発表」の場面：寝ている間にたまったものを、1 枚ずつめくって見せる演出。1 日の始まりにご褒美の瞬間を置く |
| Finch | キャラクターが画面の中心にいて、利用者の行動に毎回小さく反応する。淡いパステル、丸い形、やさしい文 |
| Duolingo | 1 本の道（進むマスの列）で「今日やること」と「積み上げ」を同時に見せる。キャラの表情で手応え |
| Forest | 「やめたら枯れる」1 つのルールが画面の主役。結果が 1 枚の絵（森）として残り、見せたくなる |
| iOS 26 の標準アプリ（Liquid Glass） | 浮いたタブバー・ガラスの操作部品・内容を画面いっぱいに。標準の部品（`TabView`・`.glassEffect`）を正しく使うと今っぽく見える |
| Locket・BeReal | ウィジェットとホーム画面が主役。アプリを開かなくても価値が届く |

## 2. 借りてよいもの・いけないもの
- **よい**：画面の組み立て（どこに何を置くか）、動きの型（めくる・せり上がる・数字が増える）、気持ちいい瞬間の置き方、情報の量
- **いけない**：キャラクター・絵・ロゴ・名前・色の組み合わせをそのまま。参考のアプリと並べて同じアプリに見える状態（審査 4.3 と権利の問題）。トーンは StudyReel から外さない

## 3. 見比べる（見直しの採点のとき）
- 撮った画面と、参考の 2 つのアプリの画面を**並べて見る**。「同じ値段で売られていたら、どちらを選ぶか」を書く。参考のほうを選ぶなら、何が足りないかを書いて直す
- 主な操作がスクロールせずに見えるか（普通の iPhone と Duo の両方）。重なり・はみ出し・入れ忘れのアイコン・素のリストが残っていないか
- 今日の Issue に「参考にしたアプリと借りたもの 3 つ」と「見比べた結果」を残す
